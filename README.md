# Bürokratik Gecikme Mazeret Jeneratörü

## Resmi Açıklama (Ciddi Gibi Görünen Ama Değil)

Bu depo, insanlık tarihinin en büyük sorunlarından birine çözüm üretmek amacıyla kurulmuştur: **GECİKME**.

Artık "trafik vardı" demek yetmiyor. Modern insan, mazeretlerini en az üç seviyede şişirmeli, bürokratik bir dille sarmalı ve sonunda varoluşsal bir sorgulamaya dönüştürmelidir. Bu araç, tam olarak bunu yapar.

### Nasıl Çalışır?

1. Python 3 ile çalıştırın:
   ```bash
   python mazeret_jeneratoru.py
   ```
2. Ya da argüman verin:
   ```bash
   python mazeret_jeneratoru.py otobüs gelmedi
   ```
3. Araç size 3 seviyeli bir mazeret sunar:
   - Seviye 1: Sıradan bahane
   - Seviye 2: Bürokratik kaçış
   - Seviye 3: Varoluşsal kriz

### Özellikler

- Gerçekten çalışır (inanmıyorsanız deneyin)
- Her seferinde farklı kombinasyonlar
- Hiçbir şeyi çözmez ama mazeretinizi güçlendirir
- Evrenin onayını almanızı hatırlatır

### Uyarı

Bu araç kullanıldıktan sonra gerçekten zamanında varıp varmamanız önemsiz hale gelir. Önemli olan mazeretin kalitesidir.
